# SLMs

Reserved for future small language models. No SLM is downloaded in this phase. Qwen3-VL is an image-and-text model and belongs in the sibling `VLM-models` folder.

When adding a model, create a descriptive subfolder and include its source, licence, exact revision or file hashes, intended projects, runtime settings and an actual test result. Store project training data and checkpoints in separate named folders on `/sdb-disk`. Do not put credentials here.
